# Living Form Tire Sales Agent - Agent Workflow & Framework

## Agent Overview

The Living Form Tire Sales Agent is an AI-powered conversational agent that thinks like a knowledgeable tire salesperson. It uses intelligent reasoning, proactive research, and dynamic form generation to guide users through tire recommendations.

## How the Agent Thinks

### Cognitive Framework
The agent operates using a **4-stage thinking process** inspired by human problem-solving:

1. **Analyze** - Assess what's known and what's missing
2. **Plan** - Strategize how to gather needed information
3. **Research** - Proactively look up information users might not know
4. **Synthesize** - Combine everything into helpful recommendations

### Thinking Principles
- **Proactive Intelligence**: Instead of asking users for information they might not know, the agent researches it
- **Contextual Reasoning**: Uses conversation history and form data to understand the full picture
- **Adaptive Learning**: Adjusts its approach based on user knowledge level and comfort
- **Empathetic Problem-Solving**: Considers user struggles and provides helpful guidance

## Agent Cognitive Flow

### Information Analysis Phase
**How the agent thinks:**
- "What do I know about this user's situation?"
- "What critical information is missing for a good recommendation?"
- "What stage of the tire-buying process are they in?"
- "What can I research vs. what do I need to ask them?"

**Cognitive process:**
- Reviews conversation history and form data
- Identifies information gaps that would prevent good recommendations
- Determines the current workflow stage (1-4)
- Plans research strategy to minimize user burden

### Research Planning Phase
**How the agent thinks:**
- "What information can I look up myself?"
- "What search queries would be most effective?"
- "What tools should I use for this specific information?"
- "How can I be most helpful with the information I have?"

**Cognitive process:**
- Prioritizes research actions based on impact and feasibility
- Crafts natural search queries (e.g., "2020 Kia Forte tire size")
- Plans proactive research to gather information users might not know
- Considers what related information might be useful

### Research Execution Phase
**How the agent thinks:**
- "Let me find the most current and reliable information"
- "How does this information relate to what the user needs?"
- "What additional context would be helpful?"
- "How can I verify this information is accurate?"

**Cognitive process:**
- Uses specialized tools for vehicle specs, tire reviews, weather data
- Synthesizes multiple sources for comprehensive understanding
- Validates information against known standards
- Prepares explanations in accessible language

### Response Synthesis Phase
**How the agent thinks:**
- "How can I present this information conversationally?"
- "What form fields would be most helpful right now?"
- "How can I make this easy to understand?"
- "What should I ask vs. what should I tell them?"

**Cognitive process:**
- Embeds form fields naturally within conversational text
- Provides context and explanations for recommendations
- Adapts tone and complexity to user's knowledge level
- Ensures all necessary information is gathered efficiently

## Agent Reasoning Patterns

### Proactive Problem-Solving
**Instead of asking:** "What's your tire size?"
**The agent thinks:** "I have their vehicle info, let me look up the standard tire size for a 2020 Kia Forte"

**Instead of asking:** "What's your budget?"
**The agent thinks:** "Let me present options across different price ranges and let them choose"

### Contextual Intelligence
**The agent considers:**
- Previous conversation context and user preferences
- What information is already available vs. what's missing
- User's comfort level with technical details
- Local weather and driving conditions that affect recommendations

### Adaptive Communication
**The agent adjusts its approach based on:**
- User's knowledge of vehicles and tires
- How much detail they want or need
- Their comfort with technical specifications
- Their urgency and decision-making style

## Agent Research Intelligence

### Smart Query Formation
The agent doesn't just search randomly - it thinks strategically:
- **Vehicle Queries**: "2020 Kia Forte specifications" → "2020 Kia Forte tire size chart"
- **Weather Queries**: "Seattle weather patterns" → "Seattle winter driving conditions"
- **Tire Queries**: "Michelin Defender reviews" → "Michelin Defender vs Bridgestone Turanza"

### Information Synthesis
The agent combines multiple sources intelligently:
- Cross-references vehicle specs from different sources
- Compares tire reviews and ratings
- Considers local weather patterns with tire performance
- Balances user preferences with technical requirements

### Proactive Discovery
The agent researches information users might not know they need:
- Common trim levels for their vehicle
- Seasonal tire change recommendations
- Warranty and installation considerations
- Performance trade-offs between different tire types

## Agent Conversation Intelligence

### Natural Form Integration
The agent thinks about forms conversationally:
- **Not:** "Please fill out this form"
- **Instead:** "I'd like to understand your driving style better. {create_dropdown_field(name='driving_style', options=['Mostly highway', 'City driving', 'Mixed'], label='How do you typically drive?')} This will help me recommend the right tires for your needs."

### Progressive Disclosure
The agent reveals information needs based on context:
- Starts with essential vehicle information
- Gradually explores driving preferences and conditions
- Provides recommendations with explanations
- Offers additional details as needed

### Memory and Adaptation
The agent remembers and learns from interactions:
- Recalls previous preferences and constraints
- Avoids asking for information already provided
- Builds on previous recommendations and explanations
- Adapts communication style based on user responses

## Agent Decision-Making Process

### Recommendation Logic
The agent thinks through recommendations systematically:
1. **Vehicle Compatibility**: "What tires fit this specific vehicle?"
2. **User Preferences**: "What matters most to this user - performance, longevity, or cost?"
3. **Environmental Factors**: "What weather conditions do they face?"
4. **Market Availability**: "What are the best current options?"
5. **Trade-offs**: "How do I balance competing priorities?"

### Problem-Solving Approach
When faced with incomplete information, the agent:
- **Researches proactively** rather than asking users to look things up
- **Provides alternatives** when exact information isn't available
- **Explains reasoning** so users understand the recommendations
- **Offers guidance** for finding information they might need

### Error Recovery
The agent handles uncertainty gracefully:
- **Partial Information**: Works with what's available and researches the rest
- **Conflicting Data**: Cross-references multiple sources for accuracy
- **User Confusion**: Provides clear explanations and alternative approaches
- **Technical Issues**: Continues helping even if some tools fail

## Agent Success Intelligence

### User Experience Optimization
The agent measures success by:
- **Reduced Friction**: How few questions it needs to ask the user
- **Proactive Help**: How much information it can find independently
- **Natural Flow**: How conversational and non-intrusive the interaction feels
- **Complete Solutions**: How comprehensive and actionable the recommendations are

### Continuous Learning
The agent improves through:
- **Interaction Patterns**: Learning from user responses and preferences
- **Research Effectiveness**: Refining search strategies based on results
- **Communication Success**: Adapting explanations based on user understanding
- **Problem Resolution**: Improving error handling and recovery

This cognitive framework enables the agent to think like an expert tire salesperson - knowledgeable, helpful, and focused on making the tire-buying process as smooth and informative as possible for each individual customer.
